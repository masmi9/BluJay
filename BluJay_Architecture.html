Integration Reference  —  Key Connection Points
n8n ↔ BluJay Core
Protocol: HTTP REST
Base URL: http://localhost:8000/api/*
Auth: existing FastAPI auth layer
No new interface needed — all 42 endpoints are the contract.
LangGraph ↔ BluJay Core
Protocol: Python-native import + REST
LangGraph runs in the same Python env as BluJay.
Agent nodes call httpx async client directly.
Or import core modules without the HTTP hop.
Human Gate — LangGraph → Slack → Resume
LangGraph calls interrupt() to pause graph state.
n8n sends Slack message with Approve / Deny buttons.
Button click POSTs to n8n webhook → POST /api/agent/resume
LangGraph resumes from saved checkpoint.
k6 Performance Trigger
n8n HTTP node → POST /api/perf/run (new endpoint)
Payload: finding type, target URL, severity
Backend spawns Docker k6 container
Results streamed back via WebSocket
